## B. 信任边界

| 边界 | 跨越什么 | 现有控制 | 可能缺口 |
|---|---|---|---|
| 浏览器 → API | 身份/参数/文件 | 鉴权、WAF、CSRF | 越权、参数篡改、上传 |
| API → DB | 查询/租户 | ORM、租户过滤 | 注入、跨租户 |
| 服务 → 第三方 | 回调/凭据 | 签名、白名单 | 回调伪造、密钥泄露 |
| 用户 → 管理员 | 角色/后台 | RBAC、独立后台 | 垂直越权、后台暴露 |
| 租户 → 租户 | tenant_id | 行级隔离 | IDOR、批量赋值 |
| 开发/测试 → 生产 | 配置/数据 | 网络隔离、凭证 | 测试环境泄露、弱口令 |
| Agent → 工具/外部内容 | 指令/数据 | 工具白名单、提示 | 提示注入、工具越权、数据外泄 |
